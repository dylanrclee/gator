Postgres and Go are required to be installed for this program.

Install gator with `go install github.com/dylanrclee/gator@latest` - enter this in your terminal.

After installation, make sure the Go bin directory is in your PATH.

Commands:
- login 'name'
- register 'name'
- reset
- users
- addfeed 'feed name' 'feed url'
- feeds
- follow 'feed url'
- following
- unfollow 'feed url'
- agg 'time interval'
- browse
